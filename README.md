# 1. Project Overview

## About Madibana Family Bakery

Madibana Family Bakery is a family-owned bakery that provides fresh and tasty baked products to customers. The bakery offers different types of products such as bread, cakes, muffins, cupcakes, pastries and other baked goods.

The purpose of this website is to provide customers with information about Madibana Family Bakery and the products that are available. The website is designed to make it easier for customers to learn about the business, explore its products and communicate with the bakery. 

Through the website, customers can view different bakery products, learn more about the business, browse product images and submit enquiries about products and services.

The website is designed to be simple, attractive and easy to use. It is intended to give customers a pleasant online experience while helping the bakery promote its products.
The website will have a simple and organised design. It will use clear navigation, images and readable text to provide customers with a pleasant user experience.
## 1.2 Purpose of the Website
The main purpose of developing the Madibana Family Bakery website is to establish an online presence for the business.
The website provides a convenient platform where customers can access bakery information without having to visit the physical store. It also helps promote the bakery's products and makes communication between the business and its customers easier.

# Content Research and Sourcing


**Research**

Research was conducted to understand the basic requirements for developing a functional and user-friendly website.
The research covered HTML, CSS, responsive design, forms, accessibility and website.

**HTML Research**

HTML5 was researched to understand how webpages are structured. HTML elements such as headings, paragraphs, lists, links, images, forms and semantic elements are used to organise website content.

**CSS Research**

CSS was researched to understand how webpages can be styled.
CSS can be used to control colours, fonts, spacing, page layout and responsive design.

**Responsive Design Research**

Responsive design was researched to understand how websites can adapt to different screen sizes.  CSS Media queries can be used to change the layout for desktop, tablet and mobile devices.

**JavaScript Research**

JavaScript was researched to understand how interactive features can be added to websites.
This research helped with implementing features such as form validation, image lightboxes, scroll animations and dynamic content.

**Forms Research**

HTML forms were researched to understand how users can enter information. The bakery enquiry form uses fields such as text inputs, email inputs, telephone inputs, date selection, radio buttons, checkboxes, a select menu and a textarea.
JavaScript validation was added to help ensure that customers provide the required information.

**Accessibility Research**

Basic accessibility practices were considered when developing the website. Images use alternative text, form fields use labels, and headings are used to organise content, providing clear navigation links and Using readable text and suitable colour contrast

**Website Design Research**

Bakery websites were reviewed to understand common features such as product galleries, product information, contact details, navigation menus and enquiry forms.

HTML5 was used to structure all website pages.

Semantic HTML elements such as <header>, <nav>, <main>, <section> and <footer> were used.
