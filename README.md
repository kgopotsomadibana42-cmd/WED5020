# 1. Project Overview

## About Madibana Family Bakery

Madibana Family Bakery is a family-owned bakery that provides fresh and tasty baked products to customers. The bakery offers different types of products such as bread, cakes, muffins, cupcakes, pastries and other baked goods.

The purpose of this website is to provide customers with information about Madibana Family Bakery and the products that are available. The website is designed to make it easier for customers to learn about the bakery and contact the business.

The website gives customers an opportunity to view the different products offered by the bakery, learn more about the business and make an enquiry about products or services.

The website is designed to be simple, attractive and easy to use. It is intended to give customers a pleasant online experience while helping the bakery promote its products.

# 2. Website Goals and Objectives

## Website Goals

The main goal of the Madibana Family Bakery website is to create an online platform where customers can easily find information about the bakery and its products.

The website aims to:

- Provide information about Kganya Family Bakery.
- Display the bakery's products.
- Allow customers to view cakes, bread, pastries and other baked products.
- Provide contact information for the bakery.
- Allow customers to make enquiries.
- Help promote the bakery and its products online.
- Make it easier for new customers to discover the bakery.

## Objectives

The objectives of the website are:

- To create a simple and user-friendly website.
- To provide clear information about the bakery.
- To display products in an organised way.
- To make contact information easy to find.
- To provide an enquiry page for customers.
- To create a professional online presence for the bakery.

# 3. Key Features and Functionality

The Madibana Family Bakery website will include the following features:

- **Home Page:** Introduces visitors to Kganya Family Bakery.
- **About Page:** Provides information about the bakery and its background.
- **Products Page:** Displays the different baked products available.
- **Services Page:** Provides information about bakery services such as custom cakes and orders.
- **Gallery Page:** Provides different baked images.
- **Enquiry Page:** Allows customers to send enquiries.
- **Contact Page:** Provides contact details and location information.
- **Navigation Menu:** Allows users to move easily between the different pages.
- **Images:** Displays pictures of bakery products.
- **Links:** Allows users to navigate between pages.

# 5. Design and User Experience

## Colour Scheme

The website will use warm and welcoming colours that represent a bakery environment.

The proposed colours include:

- **Cream:** Used for backgrounds.
- **Brown:** Represents baked products and gives the website a warm feeling.
- **Gold:** Used for highlights and important information.
- **White:** Used to keep the website clean and easy to read.

## Typography

The website will use simple and easy-to-read fonts.

Headings will be larger and bold so that users can easily identify different sections.

Paragraph text will use a clear font size that makes the information comfortable to read.

## Layout and Design

The website will have a simple and organised layout.

The navigation menu will be placed at the top of the pages so that users can easily access the different sections of the website.

Images of bakery products will be used to make the website more attractive and to give customers an idea of the products available.

The website will also be designed to work well on different screen sizes.
