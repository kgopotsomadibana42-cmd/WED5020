# 1. Project Overview

## About Madibana Family Bakery

Madibana Family Bakery is a family-owned bakery that provides fresh and tasty baked products to customers. The bakery offers different types of products such as bread, cakes, muffins, cupcakes, pastries and other baked goods.

The purpose of this website is to provide customers with information about Madibana Family Bakery and the products that are available. The website is designed to make it easier for customers to learn about the bakery and contact the business.

The website gives customers an opportunity to view the different products offered by the bakery, learn more about the business and make an enquiry about products or services.

The website is designed to be simple, attractive and easy to use. It is intended to give customers a pleasant online experience while helping the bakery promote its products.
The website will have a simple and organised design. It will use clear navigation, images and readable text to provide customers with a pleasant user experience.

# 2. Website Goals and Objectives

## Website Goals

The main goal of the Madibana Family Bakery website is to create an online platform where customers can easily find information about the bakery and its products.

The website aims to:

- Provide information about Madibana Family Bakery.
- Display the bakery's products.
- Allow customers to view cakes, bread, pastries and other baked products.
- Provide contact information for the bakery.
- Provide information about bakery services.
- Allow customers to make enquiries.
- Help promote the bakery and its products online.
- Make it easier for new customers to discover the bakery.

## Objectives

The objectives of the website are:

- To create a simple and user-friendly website.
- To provide clear and accurate information about the bakery.
- To display products in an organised manner.
- To make contact information easy to find.
- To provide an enquiry page for customers.
- To create a gallery of bakery products.
- To create a professional online presence for the bakery.
- To ensure that the website can be viewed on different screen sizes.

# Content Research and Sourcing


**Research**

Research was conducted to understand the basic requirements for developing a functional and user-friendly website.

**HTML Research**

HTML5 was researched to understand how webpages are structured. HTML elements such as headings, paragraphs, lists, links, images, forms and semantic elements are used to organise website content.

**CSS Research**

CSS was researched to understand how webpages can be styled. CSS can be used to control colours, fonts, spacing, page layout and responsive design.

**Responsive Design Research**

Responsive design was researched to understand how websites can adapt to different screen sizes. Media queries can be used to change the layout for desktop, tablet and mobile devices.

**Forms Research**

HTML forms were researched to understand how users can enter information. The bakery enquiry form uses fields such as text inputs, email inputs, telephone inputs, date selection, radio buttons, checkboxes, a select menu and a textarea.

**Accessibility Research**

Basic accessibility practices were considered when developing the website. Images use alternative text, form fields use labels, and headings are used to organise content.

**Website Design Research**

Bakery websites were reviewed to understand common features such as product galleries, product information, contact details, navigation menus and enquiry forms.

**How the Research Was Used**

The research was used in the project in the following ways:

HTML5 was used to structure all website pages.
CSS3 was used for styling.
Navigation links were used to connect pages.
Forms were used for customer enquiries.
Alternative text was added to images.
Semantic HTML elements such as <header>, <nav>, <main>, <section> and <footer> were used.
Responsive design techniques were planned for different screen sizes.
GitHub was used to manage project development.
